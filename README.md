# Holiday Timer

A Windows 11 countdown orb with tray controls, NSW workday counting and music-reactive effects.

[Download the latest installer](https://github.com/quincy-jc/holiday-timer/releases/latest/download/HolidayTimerSetup.exe)

Set your event in Settings, then drag the orb or hide it in the system tray. Workday mode excludes weekends and NSW public holidays.

Choose a companion in Settings and click the orb to interact with it.

**Updates:** Version 1.7.1 and later can update from Settings or the tray; the app restarts automatically. Exit version 1.7.0 or older and install manually once.

**Build:** Run `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1` on Windows with .NET Framework 4.8. See the [full guide](https://github.com/quincy-jc/holiday-timer/blob/main/GUIDE.md) for details.
